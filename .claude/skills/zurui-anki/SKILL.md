# ずるい暗記術スキル

偏差値30から司法試験に一発合格した佐藤大和のメソッドを、学習設計と日々の実行に落とし込む。
このスキルの仕事は「頑張り方を増やす」ことではなく、**やらないことを決めて、残った少量を高回数で回す設計に変換する**こと。

## 大前提：ゴールは理解ではなく合格（結果）

理解は暗記の反復の副産物として後から付いてくる。だから理解に時間を払わない。
これは手抜きの正当化ではなく、**合格ラインが7割前後の試験では「全部わかる」ことがそもそも要求されていない**という事実に合わせた資源配分。
相手が「ちゃんと理解しないと不安」と言ったら、否定せずこう返す ——
「理解は3周目に勝手に来る。1周目に理解を取りにいくと、3周目に到達する前に時間が尽きる」。

## 4つのコア原則

学習設計を頼まれたら、必ずこの4つの形に変換して返す。

**1. 順序を逆転する** … 参考書→問題→答え合わせ、ではなく **答えを見る → 問題を見る → 最後に参考書**。
問題を解こうとして解けない体験（挫折感）が継続を殺す最大の要因なので、そもそも解かせない。過去問の解答を「読み物」として扱う。

**2. 先に捨てる** … 出題頻度と難易度でランク分けし、やらない範囲を明文化する。
捨てる範囲を決めないと、残り時間が足りているかどうかの計算が一生できない。

**3. 短い時間 × 回数 × 勉強量 ＝ 記憶力** … 1回の濃さではなく回数で殴る。
1日15分でも毎日が正解。まとめて3時間やる日を作るより、7日に散らす。

**4. 書かずに思い出す** … ノートを作らない。書くと「勉強した気」になるが頭には入っていない。
アウトプットは声に出す・人に話す。記憶は入れる回数ではなく**引き出した回数**で強くなる。

## 学習設計の作り方（依頼されたときの手順）

1. **ゴールと期限を数字にする** … 合格点、目標点、残り日数、1日の可処分時間。ここが曖昧なままプランを書かない。
2. **配点表を出して、点の取り所を決める** … 配点が重く／基礎で取れる科目に資源を寄せる。捨て科目・捨て論点をここで宣言する。
3. **教材を1つに絞る** … 過去問集1冊が主戦場。テキストは「引く」もので「読む」ものではない。
4. **周回数を決めて、逆算で日割りにする** … 「◯◯を◯周」を先に決め、問題数÷日数で1日ノルマを出す。1問1〜2分（解かないので速い）で見積もる。
5. **1日のリズムに埋め込む** … 下のテンプレに流し込む。新しい時間を作らず、既にある時間（移動・食事・寝る前）に貼る。
6. **正直な見立てを添える** … 時間が足りないなら足りないと言う。そのうえで「この配分なら射程内」の条件を示す。

## ランク分け（先に捨てるための道具）

| 頻度 | 基準 | 扱い |
|---|---|---|
| A | 毎年のように出る | 全周回でやる |
| B | 2〜3年に一度 | 2周目以降でやる |
| C | めったに出ない | **やらない** |

| 難度 | 基準 | 扱い |
|---|---|---|
| ++ | 超基礎 | 最優先・満点を取りにいく |
| + | 基礎 | 取り切る |
| − | 応用・自分の苦手 | **やらない**（時間がかかり精神的にも苦痛で、費用対効果が最悪） |

やるのは **A/B × ++/+ のみ**。試験は基礎だけで合格ラインに届くように作られている。

## 1日のリズム（テンプレ）

| 時間帯 | やること | 狙い |
|---|---|---|
| 起床直後 5分 | 昨夜やった所を「思い出す」 | 睡眠中に整理された記憶を引き出して固定する |
| 移動・家事中 | ながら学習（アプリ・音読・音声） | 回数を稼ぐ。ここは"新規"ではなく"再会"の時間 |
| 日中 15分 | 1ページ1秒スキャン（下記） | 全体を薄く何度も通す |
| 夜 メイン | 答え→問題の反復（主戦場） | その日の新規範囲 |
| 就寝30分前 | 暗記ピーク（数字・条文・用語） | 睡眠が定着させる。ダラダラやらず一気に |

## 記憶の技術（そのまま指示に使える形で）

- **1ページ1秒スキャン** … 太字・マーカーの1ワードを1秒で「読む」のではなく「見る」。詰まっても**めくる流れを止めない**。付箋だけ貼って最後まで一気に行き、詰まった箇所をその日の課題にする。到達段階は ①ワードがわかる ②意味がわかる ③関連情報まで出てくる。
- **夜5分＋朝5分の出し入れ** … 夜に書き出し、翌朝5分で思い出す。思い出せなければ見てよい（思い出せなかった、という発見が本体）。
- **間隔を広げる** … 復習間隔を1日→2日→3日と伸ばし、**最長1週間**を目安に。
- **睡眠を削るなら90分単位**。週1回は完全オフの半日を作り、何かを「やり切る」満足で燃料を補給する。
- **長所と好きなものに紐づける** … 好きな食べ物・場所・音楽と結びつけた自分専用の型を作る。

## メンタル設計（ずるい自習術）

続かない相談が来たら、根性ではなくこの型で返す。

- 「できない主人公」になりきる（できないところから始まる物語の中にいると解釈し直す）
- 人前で目標を宣言する／自分を鼓舞するライバルを想像する
- 過度なルールと我慢を排除する（守れないルールは自己否定の生産装置）
- 自分の心の癖を把握し、感情（悔しさ・見返したい）を燃料に変える
- 行動を記録して見返す（積み上がった量そのものが自信になる）

## 試験以外への転用

新しい業界・制度・技術のキャッチアップも同じ形に落とす。
「答え」＝ 先行事例・完成物・成功パターン。まずそれを見る。原理は後から追いつく。
続編『ずるい勉強法』の核はこれ ——**個性もプライドも捨てて真似る。ゼロから作る力より、既にある知識を扱う力**。

## 出力の形

学習設計を返すときは、この順で書く。長い解説は要らない。実行できるかが全て。

```
1. ゴール（目標点／期限／残り日数）
2. 得点戦略（科目別の目標点と、捨てる範囲の明示）
3. 週次スケジュール（何を何周するか）
4. 1日のリズム（既存の時間への貼り付け）
5. チェックポイント（模試・弱点日・直前の動き）
6. 正直な見立てとリスク
```
