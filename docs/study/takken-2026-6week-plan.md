## 2. 得点戦略（＝どこを捨てるかの宣言）

| 科目 | 出題 | 目標 | 方針 |
|---|---|---|---|
| **宅建業法**（問26-45） | 20 | **18〜20** | 最優先。ここは満点を取りにいく。全体の学習時間の40%を投入 |
| **法令上の制限**（問15-22） | 8 | **6** | 数字の暗記ゲーム。都計法・建基法・国土法・農地法・宅造法の頻出数字だけ |
| **税・その他**（問23-25） | 3 | **2** | 不動産取得税／固定資産税／印紙税／登録免許税の頻出2〜3論点のみ。所得税は捨て |
| **権利関係**（問1-14） | 14 | **7** | A論点のみ。深追い厳禁 |
| **免除科目**（問46-50） | 5 | **4〜5** | 登録講習なしで全問受験。**5問中4〜5点を取りにいく**（下記） |
| 合計 | 50 | **37〜40** | |

**捨てると決めるもの（迷ったら見ない）**
- 権利関係の C ランク論点：債権譲渡、請負、委任の細目、判例の細かい射程、複雑な事例問題
- 全科目の「−」（応用・自分の苦手）と「C」（めったに出ない）
- 過去問集の難易度表示が高い問題は、2周目までは飛ばす

**免除科目（問46-50）は登録講習なしなので5問すべて受験する。ここは捨てずに取りにいく。**
この5問は範囲が固定で、学習コストあたりの得点効率が全科目で最も高い。権利関係14問に1時間かけるより、
ここに1時間かける方が確実に点になる。内訳と方針：

| 問 | 内容 | 方針 |
|---|---|---|
| 46 | 住宅金融支援機構法 | 証券化支援業務・直接融資できる場合の暗記。ほぼ毎年同じ論点 |
| 47 | 景品表示法（表示規約） | 「〜m」「〜分」の表示ルールと不当表示のパターン暗記 |
| 48 | 統計 | 直前1週間で最新数値を丸暗記。**確実に1点。ここを落とすのは損** |
| 49 | 土地 | 常識で解ける。造成地・埋立地・崖・地形の頻出パターンだけ |
| 50 | 建物 | 木造・鉄筋・基礎構造の頻出用語。過去問の使い回しが多い |

問48（統計）と問49・50（土地建物）は短時間で仕上がるので、**目標は5問中4点、狙えれば5点**。
その分、権利関係の目標は7点のまま据え置き、余裕が出たら業法の詰めに回す。

## 3. 教材の使い方（ずるい式・3ルール）

1. **問題は解かない。** 問題文を読む → すぐ解答・解説を読む。赤シートは3周目から。
2. **書かない。** ノートは作らない。ペンは○△×と付箋を貼るためだけに使う。
3. **1問1〜2分。** 悩んだら即答えを見て次へ。止まらないことが最優先。

**ランク付けのルール（1周目に全問へ書き込む）**
- 頻度：A＝毎年出る／B＝2〜3年に一度／C＝滅多に出ない → **Cは以後やらない**
- 難度：++＝超基礎／+＝基礎／−＝応用・苦手 → **−は以後やらない**
- 迷った問題・間違えた感覚のある問題に**付箋**。これが以後の「弱点リスト」になる

**分冊の扱い**（3分冊を取り外して常時1冊だけ持ち歩く）

| 分冊 | 科目 | 問題数の目安 |
|---|---|---|
| 1 | 宅建業法 | 約112問 |
| 2 | 権利関係 | 約100問 →（A論点に絞って約55問） |
| 3 | 法令上の制限 約63問／税・その他 約47問 | 約110問 |

## 4. 週次スケジュール

### W0：9/5(土)〜9/6(日) — 準備日（勉強はしない、仕込みだけ）
- 受験票の発送時期と会場を確認（登録講習なし＝5問免除なしで確定。問46-50も受験する）
- 3分冊を取り外し、付箋と赤シートを用意
- 付属の「令和7年度本試験」PDFをダウンロード（W4で使う。**今は絶対に解かない**）
- 学習アプリを入れて移動時間の枠を確保
- 仕上げに宅建業法の第1章だけ答えを読む（着火用・30分）

### W1：9/7(月)〜9/13(日) — 宅建業法1周目
- 112問 ÷ 7日 ＝ **1日16問**（約45分）。答えを読むだけ。ランク付けと付箋を同時に
- 夜5分の書き出し／朝5分の思い出しをこの週から習慣化
- 週末は遅れの回収と、業法の付箋箇所だけ再スキャン

### W2：9/14(月)〜9/20(日) — 宅建業法2周目 ＋ 法令1周目
- 業法2周目：**1日24問**（A/B・++/+のみ。Cと−は飛ばすので実質70問前後）
- 法令上の制限1周目：**1日9問**。数字（面積・日数・階数）を声に出す
- 就寝30分前は「数字だけ」の暗記ピークに固定

### W3：9/21(月)〜9/27(日) — 法令2周目 ＋ 税その他1周目 ＋ 権利1周目
- 法令2周目：1日9問（付箋中心）
- 税・その他1周目：1日7問
- 権利関係1周目：A論点55問を**1日8問**（意思表示・代理・時効・相続・借地借家・区分所有・不動産登記）
- 週の終わりに業法の付箋のみ高速スキャン（1ページ1秒）
- 税・その他の分冊に含まれる**免除科目（機構・景表法・土地・建物）もこの週で1周目**。統計だけは飛ばす

### W4：9/28(月)〜10/4(日) — 初の通し＋弱点の可視化
- **10/4(日) 13:00-15:00 に令和7年度本試験を本番と同じ時間で1回**（この6週間で唯一「解く」日）
- 採点後、落とした問題の論点だけを弱点リストに追加。点数に一喜一憂しない（30点前後で正常）
- 平日は 業法3周目（付箋のみ・1日20問）／法令3周目／権利2周目

### W5：10/5(月)〜10/11(日) — 弱点集中週
- 付箋箇所のみを高回数で回す。1問30秒〜1分
- 全分冊に**1ページ1秒スキャン**をかける（1分冊15分・毎日1冊ずつローテ）
- 10/11(日) に2回目の通し（直近年度 or 12年過去問から1年分）→ 目標35点以上
- 免除科目（機構・景表法・土地・建物）のパターン暗記をここで完了。目標は本番で4点以上

### W6：10/12(月)〜10/18(日) — 直前週（新規は入れない）
| 日 | やること |
|---|---|
| 10/12(月)〜10/14(水) | 宅建業法4・5周目（付箋のみ）。1日1周のつもりで高速 |
| 10/15(木) | 法令の数字・税の税率を寝る前ピークで一気に |
| 10/16(金) | 統計（問48）を暗記。ここで初めて最新統計を詰める |
| 10/17(土) | 会場ルート・持ち物確認。業法の付箋のみ1周。**新規禁止・早寝** |
| 10/18(日) | 朝5分の思い出し → 会場へ |

**当日の解く順序**：問26〜45（業法）→ 問15〜22（法令）→ 問46〜50（免除）→ 問23〜25（税）→ 問1〜14（権利）

## 6. 正直な見立て

- **6週間108hは、初学者の標準（約300h）の3分の1**。ゼロスタートなら合格確率は五分を下回る。ただし業法18＋法令6＋免除4＝28点を土台にできれば、権利で5点拾って33点、近年のラインには手が届く。**業法の完成度が全て**。
- 学習経験がある・不動産実務に触れているなら、この配分は十分に射程内。
- **最大のリスクは権利関係に時間を吸われること**。民法は面白くて深いので沼にはまる。「権利は7点でいい、14点取りにいかない」を毎週自分に確認する。
- 遅れが出たら削るのは権利関係と税、**絶対に削らないのは宅建業法と免除科目**。免除科目5問は投下時間あたりの得点効率が最も高く、ここを削るのは自殺行為。
