## 2. 得点戦略（＝どこを捨てるかの宣言）

| 科目 | 出題 | 目標 | 方針 |
|---|---|---|---|
| **宅建業法**（問26-45） | 20 | **18〜20** | 最優先。ここは満点を取りにいく。全体の学習時間の40%を投入 |
| **法令上の制限**（問15-22） | 8 | **7** | 数字の暗記ゲーム。都計法・建基法・国土法・農地法・宅造法 |
| **税・その他**（問23-25） | 3 | **2〜3** | 不動産取得税／固定資産税／印紙税／登録免許税。所得税は最後に回す |
| **権利関係**（問1-14） | 14 | **9** | A論点＋連帯債務・保証・債権譲渡・相殺・請負・委任まで拡張 |
| **免除科目**（問46-50） | 5 | **4〜5** | 登録講習なしで全問受験。**5問中4〜5点を取りにいく**（下記） |
| 合計 | 50 | **40〜44** | |

**捨てると決めるもの（迷ったら見ない）**
- 判例の細かい射程、複雑な事例問題、条文番号の暗記
- 全科目の「−」（応用・自分の苦手）と「C」（めったに出ない）
- 過去問集の難易度表示が高い問題は、3周目までは飛ばす

> 週30時間確保できるため、当初捨てていた権利関係のB論点（連帯債務・保証・債権譲渡・相殺・請負・委任）を W3 で拾い直し、目標を7点→9点に引き上げている。捨てる基準そのものは変えない。

**免除科目（問46-50）は登録講習なしなので5問すべて受験する。ここは捨てずに取りにいく。**
この5問は範囲が固定で、学習コストあたりの得点効率が全科目で最も高い。権利関係14問に1時間かけるより、
ここに1時間かける方が確実に点になる。内訳と方針：

| 問 | 内容 | 方針 |
|---|---|---|
| 46 | 住宅金融支援機構法 | 証券化支援業務・直接融資できる場合の暗記。ほぼ毎年同じ論点 |
| 47 | 景品表示法（表示規約） | 「〜m」「〜分」の表示ルールと不当表示のパターン暗記 |
| 48 | 統計 | 直前1週間で最新数値を丸暗記。**確実に1点。ここを落とすのは損** |
| 49 | 土地 | 常識で解ける。造成地・埋立地・崖・地形の頻出パターンだけ |
| 50 | 建物 | 木造・鉄筋・基礎構造の頻出用語。過去問の使い回しが多い |

問48（統計）と問49・50（土地建物）は短時間で仕上がるので、**目標は5問中4点、狙えれば5点**。
その分、権利関係の目標は7点のまま据え置き、余裕が出たら業法の詰めに回す。

## 3. 教材の使い方（ずるい式・3ルール）

1. **問題は解かない。** 問題文を読む → すぐ解答・解説を読む。赤シートは3周目から。
2. **書かない。** ノートは作らない。ペンは○△×と付箋を貼るためだけに使う。
3. **1問1〜2分。** 悩んだら即答えを見て次へ。止まらないことが最優先。

**ランク付けのルール（1周目に全問へ書き込む）**
- 頻度：A＝毎年出る／B＝2〜3年に一度／C＝滅多に出ない → **Cは以後やらない**
- 難度：++＝超基礎／+＝基礎／−＝応用・苦手 → **−は以後やらない**
- 迷った問題・間違えた感覚のある問題に**付箋**。これが以後の「弱点リスト」になる

**分冊の扱い**（3分冊を取り外して常時1冊だけ持ち歩く）

| 分冊 | 科目 | 問題数の目安 |
|---|---|---|
| 1 | 宅建業法 | 約112問 |
| 2 | 権利関係 | 約100問 →（A論点に絞って約55問） |
| 3 | 法令上の制限 約63問／税・その他 約47問 | 約110問 |

## 4. 週次スケジュール

**1日5ブロック固定**（朝60分・昼45分・夕60分・夜30分・就寝前30分＋散歩音読20分）。
まとめて3時間やる日を作らない ── 短時間×高回数が記憶定着の公式。

### W0：9/5(土)〜9/6(日) — 仕込み
- 3分冊を取り外し、付箋・赤シート・ペンを用意
- 「令和7年度本試験」PDFをダウンロード（**今は絶対に解かない**）
- **12年過去問題集（年度別）を発注**。9/28からの実戦フェーズで使う
- 5ブロックをカレンダーに固定枠として入れる（通勤ゼロなので"ながら"枠がない。**散歩音読20分**で代替する）
- 宅建業法 第1章だけ答えを読む（着火・30分）

### W1：9/7(月)〜9/13(日) — 業法2周＋法令1周＋権利を並走
- 朝：前日の業法を○×で高速再確認
- 昼：法令上の制限 1周目（9問／日、7日で63問完走）
- 夕：宅建業法 1周目 28問／日 → 4日で完走、9/11から2周目 37問／日
- 夜：権利関係を1日1論点（意思表示→代理→時効→抵当権→債務不履行→契約不適合→賃貸借）
> 初日の朝だけは教科書で業法の全体像を1回通す。理解に時間を使うのはこの1回きり。

### W2：9/14(月)〜9/20(日) — 税・免除を入れて全科目1周完了
- 法令2周目・3周目、税とその他（免除科目を含む47問）を1〜2周
- 権利は借地借家 → 相続 → 区分所有 → 不動産登記まで進めて1周完了、後半から2周目
- 業法は3周目に入る
> 統計（問48）だけは触らない。最新数値は10/16に一気に詰める。

### W3：9/21(月)〜9/27(日) — 4〜5周目＋権利の守備範囲を広げる
- 業法4〜5周目（付箋のみ）、法令4〜5周目、税3周目、免除科目2周目
- **権利のB論点を追加**：連帯債務・保証／債権譲渡・相殺／請負・委任
- 論点特化デー：35条と37条の対比／8種制限／報酬計算10問連続
- 9/27に業法・法令を全問○×（時間計測）して実戦フェーズに備える

### W4：9/28(月)〜10/4(日) — 実戦フェーズ①
- 年度別を**半分ずつ**解いて即日復習（令和7年度 → 令和6年度）
- **10/4(日) 13:00-15:00 令和5年度を本番と同じ時間で完全通し。目標38点**
> 通しは「解く練習」ではなく「引き出せるかの検査」。復習まででワンセット。解きっぱなしにしない。

### W5：10/5(月)〜10/11(日) — 実戦フェーズ②（週2回の通し）
- **10/7(水) 令和4年度 通し（目標40点）／ 10/11(日) 令和2年度 通し（目標42点）**
- 間の日は、落とした論点を論点別過去問に戻って潰す
> 5回の通しで本番の時間感覚が身体に入る。2時間で50問＝1問2.4分。業法は1問1分で抜ける状態が理想。

## 5. 1日のリズム（週約30時間・通勤ゼロ版）

| 時間帯 | やること | 分 |
|---|---|---|
| 朝 | 前日の範囲を○×で高速再確認（＝思い出し） | 60 |
| 昼休み | 法令・税の数字 | 45 |
| 夕（終業後） | その日の新規（主戦場） | 60 |
| 夜 | 権利関係を結論だけ | 30 |
| 就寝30分前 | 数字・用語の暗記ピーク（一気に、ダラダラしない） | 30 |
| 散歩 | 詰まった肢を声に出す（通勤ながらの代替） | 20 |

- テレワークで移動時間がないぶん、**散歩音読を固定枠にする**。歩きながら思い出すのは、ずるい暗記術の「散歩」と「思い出し」を同時に満たす唯一の型
- 復習間隔は 1日 → 2日 → 3日 → 最長1週間 で広げる
- 週1回は半日オフ。睡眠を削るなら90分単位で
- **1回のブロックを90分以上に伸ばさない**。時間が増えたぶんはブロック数で吸収する

## 6. 正直な見立て

- **週30時間×6週＝約180時間**は、初学者の標準（約300h）の6割。ゼロスタートでも十分に射程内で、学習経験があるなら余裕を持って合格圏に入る。
- 土台は 業法18＋法令7＋免除4＋税2＝**31点**。ここに権利9点を足して40点。近年の合格ライン（33〜38）に対して**+2〜7点のマージン**を持って本番に入る設計。
- **最大のリスクは権利関係に時間を吸われること**。目標を7点→9点に上げたが、これは「B論点を拾う」であって「深く理解する」ではない。登場人物と「誰が勝つか」の一行暗記を最後まで崩さない。
- 次のリスクは**長時間ブロック化**。時間があると1回を3時間に伸ばしたくなるが、それは短時間×回数の公式に反する。ブロックを増やして間隔を空ける方が伸びる。
- 遅れが出たら削るのは権利のB論点と税、**絶対に削らないのは宅建業法と免除科目**。
