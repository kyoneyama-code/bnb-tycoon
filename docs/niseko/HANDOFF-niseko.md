### ③ 1階に住戸（2LDK）は現存しない

浄化槽算定計算書の内訳：

- 住宅部分：1階＝**車庫（算定除外）**／2階 104.34㎡／3階 93.57㎡／算定面積合計 197.91㎡ → 算定人員7人

→ 1階は車庫＋倉庫・事務所・店舗16.14㎡で、**住戸の割り当てがない**。
　 2LDKを置くなら**車庫からの新規転用**になる。

## 2. 会長から出ている検討依頼（未完了）

### 2-1. 1階2LDKをMTRが持つ／借りる場合の利回り

前提：全体運営はMTRでは無理 → ホテル（民泊）運営もレストラン運営もAPが担う。
MTRは1階の2LDKだけを持つ、または**APから賃料を決めて借りる**。

**※【2026/10/22 要再計算】1階は150.71㎡で確定（193.6㎡は誤り）。飲食100㎡＋2LDK70㎡＝170㎡は入らない。**
下表は70㎡・定員4〜6名を仮置きした旧試算。住戸は最大50㎡程度（1LDK相当）となり、定員減でADR前提も変わる。

投資（単位：万円）

| 項目 | 金額 | 備考 |
|---|---|---|
| 土地按分（70/391.52＝17.9%） | 2,325 | 1.3億×17.9% |
| 車庫→2LDK転用（断熱・給排水・サッシ・内装） | 1,000 | 車庫転用は通常の客室改装より高い |
| 水回り・設備 | 300 | |
| 家具・什器 | 300 | |
| 計 | **3,925** | |

収入：民泊1ユニット＝冬ADR12万×100日×75%＝900万／夏ADR4万×150日×35%＝210万 ＝ **年1,110万**
（`niseko-mtr-business-plan.xlsx` MTR収支シートの標準前提と同じ）

| ケース | 内容 | NOI | 利回り | 償却後 |
|---|---|---|---|---|
| ① 所有してAPに貸す | 家賃444万（宿泊売上の40%・月37万） | 389 | 9.9% | 6.2% |
| ② 所有して自ら運営 | 売上1,110−運用費477(43%)−固都税55 | 578 | **14.7%** | 11.0% |

③ APから借りる場合（所有しない・投資は内装什器1,600万のみ）

| MTRが払う家賃 | MTR利益 | 投資1,600万に対する利回り |
|---|---|---|
| 444万（売上の40%） | 189 | 11.8% |
| 300万 | 333 | 20.8% |
| 200万 | 433 | 27.1% |

→ **賃料を下げるほど利回りが上がる＝MTRが賃料を決めるなら利回りは作れてしまう。**
　 ③は「利回りいくらか」ではなく「グループ内でどちらに利益を置くか」の問題。
　 同族間取引なので適正賃料（第三者間価格）を外すと寄附金認定・移転価格の論点。賃料の根拠資料が先に要る。

→ 現時点の推奨は**②（所有して1室だけ管理委託で運営）**。
　 会長の「全体運営は無理」は3業態＋4ユニットの話で、2LDK1室は管理委託で回る
　（南千歳モデルの「Bスタート＝名義＋管理責任のみ月1.5万」がそのまま使える）。

**未解決の付随論点**
- **車庫が消える**：1階を飲食100㎡＋2LDK70㎡にすると駐車スペースが無くなる。
  ニセコは冬の除雪・送迎で駐車場が必須。代替確保が前提条件。
- **浄化槽がさらに悪化**：既に10人槽→100〜140人規模が最大リスク。2LDKが4ユニット目になると算定人員が上積み。
- **区分所有の敷地権割合**：床按分(17.9%)か収益按分(24.5%)かで利回りが9.9%〜12%と動く。
  利回りは按分の置き方で作れてしまうので、第三者鑑定を入れたほうが安全。

## 3. 別件：1.6億円の別荘（単体案件）

ビレッジ物件とは**別の案件**として会長から相談があったもの。成果物はPDF化済み。

→ `docs/niseko/niseko-villa-160m-scenarios.pdf`（A4・4ページ）

要旨：
- 1棟貸し別荘1.6億・定員10名想定。冬ADR20万×100日×80%／夏ADR6万×150日×35%（標準）
- 3構造を比較：①APに全部貸す 4.0% ／ ②MTR通年直営 5.1% ／ **③冬MTR直営＋夏AP寮 5.5%**
- 夏の民泊はNOI180万しか生まないが、AP寮として貸せば240万が丸ごと入る → ③が最良
- 借入後（LTV70%・2.5%・25年＝年返済603万）：①は+37万でほぼトントン、③は+269万
- 冬ADR±1万で±0.29pt、冬稼働±5ptで±0.36pt → **冬の2変数で利回りの約8割が決まる**
- 年間稼働132泊＜180日のため民泊新法（届出）で成立。旅館業許可は不要
- 家賃を設定する場合：冬 月150〜160万／夏 月16万（民泊連動）または月30万（AP寮の最低保証）

実勢の賃貸相場（参考・外部調査）
- 冬期戸建（ヒラフ137.4㎡）¥655,500 ※月額か期間一括か不明
- 夏期7LDK（5〜11月末）月40万／通年戸建（倶知安）月18.5〜25.5万／2LDKコンドミニアム 月8.95万〜
- → **通年で普通に貸すと月25万＝年300万＝1.9%。だから民泊負担力ベースで取るしかない。**

**この別荘案件も、所在地がニセコ町か倶知安町かが未確定**（倶知安町は宿泊禁止エリアが多い）。

## 6. モデルの共通前提（引き継ぎ用）

- 民泊運用費率：OTA手数料15% ＋ 清掃・運営15〜20% ＋ 管理委託8〜10%
  → 保守45% / 標準43% / 強気38%
- 冬：12〜3月の100日（ニセコ100日戦争）。夏：4〜11月のうち150日
- 固定資産税：(土地+建物)×1.4%。トレーラーハウスは車両扱いで対象外
- 飲食のFLR：F33% / L27% / R4.8%（AP181店FY25実績で較正）
- 飲食からMTRへの賃料：年1,200万（固定）
- 宿泊のマスターリース賃料：宿泊売上の40%
  （ホテルの固定賃料型は年商15〜25%が目安だが、あれは運営者が人件費を全部背負う前提。
  　1棟貸し民泊は運用費43%で済むため、残り57%のうち7割を家賃に乗せられる）
